Title, Summary, and Team Members

Summary

Our project is an interactive simulation of virtual saran wrap that combines GPU-accelerated cloth physics with thin-film optics. Users can interact with the saran wrap by clicking and dragging it to stretch the material. A custom shader will render iridescent rainbow patterns across the stretched and thinned-out areas.

Problem Description

Simulating realistic thin plastic materials like Saran Wrap poses a unique challenge at the intersection of physics and rendering, as they behave very differently from traditional cloth due to their strong adhesion, extreme thinness, and nonlinear deformation when stretched. This is especially the case over objects or wet surfaces. Existing cloth simulation models do not accurately capture these properties—for example, particularly the way the material clings tightly, stretches unevenly, and exhibits changing optical effects as its thickness varies.

This problem is important because it extends beyond standard cloth simulation to model more complex, real-world materials, with applications in high-fidelity rendering and interactive graphics systems. To address this, we propose extending a GPU-accelerated cloth simulation framework to incorporate adhesion forces, high damping, and variable thickness based on strain, and using this thickness to drive a custom shader that renders thin-film interference. This can then enable both realistic physical interaction and visually accurate iridescence in an interactive system.

Goals and Deliverables

What We Plan to Deliver

  1. Thin-sheet simulation
  2. Gravity-driven motion
  3. Self-collision and collisions with rigid objects
    • Wrinkling and folding behavior
    • Sticking behavior
  4. Transparent material with reflection and refraction
  5. Approximate thin-film iridescence shader
  6. Interactivity
    • Mouse-based click and drag constraints
    • Real-time response
  7. FPS measurements for different scene complexities for performance analysis
  8. Visual comparison with real-world behavior

What We Hope to Deliver

  1. Physically-based iridescence
    • Wavelength-dependent interference model
    • Changes with film thickness (and therefore stretching)
  2. Thickness-dependent appearance
  3. Surface interaction variants
    • Dry vs. wet surfaces
    • Electrostatic effects

Questions We Would Like to Answer

  • How are thin films simulated differently compared to standard cloth?
  • How can thin-film interference be approximated efficiently for real-time rendering?
  • How does deformation affect interference and perceived color?
  • What level of physics is necessary to achieve visually accurate saran wrap?

Schedule

Week 1

Goal: Set up scaffolding and do initial research

  • Set up WebGL/WebGPU and rest of scaffolding
  • Implement a basic cloth simulation with realistic physics
    • Define the particle/grid data structure for the cloth mesh
    • Write the initial compute shader
    • Implement basic structural and shear spring constraints

Week 2

Goal: Implement collision detection and begin implementing realistic saran wrap physics

  • Adjust cloth physics to mimic saran wrap
    • Adjust the spring constants
    • Implement heavy damping/friction
  • Add 3D bowl object
    • Import bowl geometry
    • Set up the transformation matrix to place it correctly
  • Implement collision detection between the mesh and bowl

Week 3

Goal: Finish implementing saran wrap physics and create custom shader

  • Write the math in the compute shader to calculate the localized stretch/strain ratio of the mesh faces
    • Write a function to map the strain ratio to a physical thickness range in nanometers based on conservation of mass
    • Pass this calculated thickness array from the compute shader into the vertex/fragment pipeline
  • Implement the thin-film interference BRDF in the fragment shader to render iridescence
    • Write the phase-shift equations to calculate optical interference

Week 4

Goal: Implement interactivity and complete remaining shader work

  • Implement real-time user interaction (mouse-drag raycasting) so the user can actively stretch the plastic
    • Set up mouse event listeners
    • Apply a localized positional constraint/force in the compute shader to let the user pull the mesh
  • Optimize the compute shader to ensure stability during interaction

Resources

For our project, we will mainly be using references for 3 key features: adhesive cloth dynamics using “Wet cloth animation with vertex based adhesion force model” by Min Ju Park and Hae Won Byun from Korea University; rendering of wet materials using “Rendering of Wet Materials” by Henrik Wann Jense, Justin Legakis, and Julie Dorsey from MIT; and thin-film interference from “The Mathematics of Thin-Film Interference” by Alan Zucconi. The foundation of our software will be from previous homeworks, such as hw4, cloth simulation. We will also be using Blender for environment modeling and OpenGL for interactive real-time previews of our simulation.

Most of the development will be done on personal computers, including Apple MacBooks and Windows-based laptops. We will also be utilizing LLM models such as Anthropic Claude and Google Gemini to assist in setting up our codebases.
